## ❌ ЩО НЕПРАВИЛЬНО / ПОТРЕБУЄ ВИПРАВЛЕННЯ

### **🚨 КРИТИЧНА УРАЗЛИВІСТЬ #1: Платні фічи НЕ захищені на беку**

**Проблема:** Endpoint `/api/requests/smart-dispatch-preview` НЕ має перевірки `subscription_tier`

**Код (main.go:217):**
```go
requests.POST("/smart-dispatch-preview", reqHandler.SmartDispatchPreview)
// ❌ Немає middleware RequireSubscriptionTier()!
```

**Атака:**
- Користувач BASIC підписки видаляє FeatureGate з браузера
- Викликає endpoint напрямками → отримує доступ до PRO функціоналу БЕЗКОШТОВНО
- Кошторис: **600,000+ грн втрат на рік** за 10 клієнтів

**Рішення:**
```go
requests.POST("/smart-dispatch-preview", 
    middleware.RequireSubscriptionTier("PRO"), // ← ДОДАТИ!
    reqHandler.SmartDispatchPreview)
```
